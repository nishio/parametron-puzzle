# パラメトロン計算機パズル

**遊ぶ: https://nishio.github.io/parametron-puzzle/**

3入力の多数決から、AND → OR → 2入力回路のねじり練習までがチュートリアルです。その後、XOR → 半加算器 → セレクター → 全加算器へ進みます。

最初の画面は目的の一文と「はじめる」ボタンだけです。次の画面で大きな0を押し、その後、実際の回路と配線を順に練習します。既存の進捗は維持され、問題メニューの「遊び方」やURLの `?welcome=1` から入口を開けます。[変更前後と初見レビューの記録](reviews/onboarding.md)。

多数決の練習では、A・B・Cが1票ずつ投票する仕組みを先に説明します。1が2票で結果1、0が2票で結果0になることを順に試してから、AND回路へ進みます。
この練習では説明・回路・票数・ボタンを小さなひとつの枠にまとめ、押す数字だけを強調します。編集用ツールは出さず、回路の位置も固定します。2本線についての補足は必要なときに開けます。後の課題では広い編集画面を使えます。

ANDの導入も同じ枠・同じ「多数決」「結果」の名前で続けます。3票目を固定0へつなぎ、A・Bを両方1にした場合と、Bだけ0にした場合を比較してからクリアを確認します。[修正後の初見レビュー](reviews/and-introduction-fixed.md)。`?and-guide=1` はANDの復習用で、保存済みの回路・配置・設計図・自己ベストを変えずに最初から試せます。

回路エディタには[React Flow（@xyflow/react）](https://reactflow.dev/)を使います。
ノード移動、端子からの接続、配線描画、選択・削除、パン、ズーム、ミニマップはReact Flow標準の機能です。
自動整列は[Dagre](https://github.com/dagrejs/dagre)です。自前のドラッグ・配線ルーティング処理はありません。

## 操作

- 出力端子から入力端子へドラッグして接続。端子を順にクリック／タップしても接続できます。
- 素子は小さなSVG記号で表示します。見出し・記号をつかんで移動。背景をドラッグして盤面を移動。
- 1信号は2本の配線です。3組の入力を片側3本ずつ、別々の2つの集約点につなぎます。2つの点を小さな輪で囲んで、ひとつの素子を表します。
- 線と端子は、そこを流れる信号に応じて0が青、1が黄、未確定が灰色になります。対になる線は互いに反対の信号を運び、ねじると上下が入れ替わります。
- 固定信号0と1は独立したノードです。それぞれ動かして配置を保存できます。
- AND／ORなどのブループリントを設置すると、固定信号はパラメトロンの入力に設定済みになります。「固定0／固定1」の入力は、外の固定信号ノードからケーブルを引く必要がありません。枠を外しても設定は残ります。
- 素子は常にSVG記号で表示します。見出しの×、または選択してDelete／Backspaceで削除できます。
- 盤面は画面全体の高さを使います。「説明を畳む」で横幅も広げられます。スマホでは「説明とテスト」で説明パネルを開きます。
- 左下の標準コントロールで拡大・縮小・全体表示。スマホではピンチも使えます。
- 素子を追加しても、既存の位置や表示範囲は動きません。新しい素子だけ空いた場所に置きます。「配置を整える」を押したときにDagreが全体を整列します。
- 配線を選ぶと、2本とも両端の素子と一緒に強調します。入力端子の名前で接続元を確認できます。
- 選んだ線を外すか、選択後Delete／Backspaceで削除。各入力・出力の2本線トグルを押すと「平行／ねじり」を切り替えます。平行は信号をそのまま通し、ねじりは0と1を入れ替えます。
- ORの次に、配線済みの回路でねじりを試す短いチュートリアルがあります。真理値表の0・1両方で反転を確かめられます。
- ねじりの練習は「A=1かつB=0のときだけ1」を作る2入力の課題です。XOR・半加算器・セレクターは素子のない盤面から始めます。
- 真理値表の行をクリック／タップすると、その入力を回路に反映します。キーボードでは行の選択ボタンを使えます。
- 出力欄は正解の値と✅／❌で現在の回路との一致を示します。未接続は「—」、選択中の入力は行の枠で示します。
- 各課題のクリア時に結果ダイアログが開きます。AND／OR／XORではブループリントをアンロック。「次へ」で次の課題へ進むか、「回路を見る」で盤面に戻れます。閉じた結果は「クリア結果」で再表示できます。
- 半加算器は4個で通常クリア、3個で理論最小クリアです。通常クリア後に3個へ減らした場合も、理論最小の達成ダイアログが開きます。
- セレクターではS=0ならA、S=1ならBを出力する3入力の回路を作ります。最少3個です。

計算素子はすべて、3入力の多数決をとるパラメトロンです。AND・OR・XORの独立した論理ゲートは置きません。
クリアした回路はブループリントとして保存されます。上部の「パラメトロン」「AND」「OR」「XOR」ボタンで直接設置できます。ブループリントのボタンを押すと、自分が作った回路のパラメトロン・内部配線・定数・反転を複製します。
設置後も内部のすべての素子と配線が見え、直接編集できます。設計図のA・Bと書かれた未接続端子に外部の信号をつなぎます。複数の端子に分岐する場合も実際の配線です。
青い枠はReact Flow標準のグループで、見出しで回路全体を動かせます。「枠を外す」は回路を残してグループだけ解除し、「×」は含まれるパラメトロンを取り外します。
個数は実際のパラメトロン数で数えます。設計図の枠・反転・定数・分岐は無料です。
全加算器はブループリントで構成した9素子でもクリアでき、配線や素子を共有すれば最少3素子です。
循環する配線は接続時に拒否します。ノードの作成順・画面上の順序は計算結果に影響しません。

進捗・獲得した設計図・自己ベスト・配置はlocalStorageに保存します。
以前のAND・OR・XOR部品の保存データは、保存済み回路の実際のパラメトロンと配線へ移行します。保存データや回路を外部サービスへ送信する処理はありません。

## 開発・検証

Node.js 22.12以降:

```sh
npm ci
npm test
npm run build
npm run test:browser
```

- `editor/src/main.jsx`: React Flowとゲーム画面
- `editor/src/nodes.jsx`: SVG素子・削除ボタンとReact Flow標準端子
- `editor/src/PairPort.jsx`, `editor/src/PairEdge.jsx`, `editor/src/pairs.css`: 二極の端子と2本組の配線。経路計算はReact Flowの`getBezierPath`を使います。
- `editor/src/engine.js`: 多数決の論理シミュレータ・実素子数での採点・保存データの正規化
- `editor/src/blueprints.js`: 保存済み回路の複製・グループ解除・旧部品の移行
- `editor/src/layout.js`: Dagreによる回路・設計図内部の配置（描画・接続・グループ移動はReact Flow標準）
- `editor/src/WiringToggle.jsx`, `editor/src/wiring.css`: 平行／ねじりトグルと説明用の2本線表示
- `editor/src/style.css`, `editor/src/workspace.css`: 盤面・SVG素子の見た目
- `vite.config.js`: React/Viteの設定
- `docs/`: GitHub Pagesへ配信するビルド結果

GitHub Pagesの配信元は`main`ブランチの`/docs`です。
変更時は`npm run build`を実行し、ソースと生成された`docs`のファイルを一緒にコミットします。
実行時のライブラリはビルドへ同梱するため、CDNやChatGPTの機能に依存しません。

`npm test`は全問題の真理値表、設計図の実回路への複製・定数・反転・独立性・旧部品の移行、保存復元、作成順と独立した計算、循環防止、3素子の下限を検証します。
`npm run test:browser`は、インストール済みのMicrosoft Edgeを独立したヘッドレス環境で使います。
React Flow標準のクリック／タップ接続、追加時の既存位置・ズームの維持、×・Deleteでの削除、配線の描画と選択、反転、ドラッグ・グループ移動、保存復元、明示的な自動整列、ブループリントの設置・枠の解除・取り外し、全課題のクリアダイアログ、4／3素子の半加算器、セレクター、9／3素子の全加算器を実操作で確認します。
ローカルビルドはPlaywrightのリクエスト処理で読み込むため、確認用サーバーや新しいポートは不要です。
`SITE_URL`を指定すれば、公開URLで同じ検証を行います。
画像はGit管理外の`.artifacts/react-flow-review/`へ保存します。
